## 📋 Descripción

**Tweet Manager** es una aplicación web que permite a los usuarios escribir, guardar y administrar tweets utilizando el LocalStorage del navegador. Esta aplicación demuestra el uso práctico de las APIs del navegador para persistir datos localmente sin necesidad de un servidor backend.

## ✨ Características

- 📝 **Escritura de Tweets**: Interfaz intuitiva para crear nuevos tweets
- 💾 **Persistencia Local**: Los tweets se guardan automáticamente en LocalStorage
- 📱 **Diseño Responsivo**: Compatible con dispositivos móviles y desktop
- 🗑️ **Eliminación de Tweets**: Capacidad de eliminar tweets individuales
- 🔄 **Carga Automática**: Los tweets persisten entre sesiones del navegador
